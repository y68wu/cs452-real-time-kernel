# CS452 early development snapshots

These are archived source snapshots of my University of Waterloo CS452 train-control coursework. They preserve earlier implementation stages that were substantially changed in the [main portfolio version](https://github.com/y68wu/cs452-real-time-kernel) and are not presented as separate finished projects.

| Directory | Stage |
| --- | --- |
| `cs452/` | Initial A0 hardware and train-control work |
| `cs452-backup-before-a0-restart/` | A0 restart backup with measurements and modular code |
| `cs452_kernel/` | Kernel 1–4 and early TC1 work |
| `cs452-kernel-tc2-branch/` | Early TC2 branch from the kernel repository |
| `cs452_kernel2/` | Later kernel milestone snapshot |
| `cs452_kernel3/` | Later kernel milestone snapshot |
| `cs452-tc2-zone-intermediate/` | Intermediate TC2 zone-controller copy from the remote workspace |
| `cs452-tc2-zone-copy/` | Another TC2 zone-controller copy with distinct dispatcher and test revisions |

These are source-only exports of the corresponding UW GitLab repositories. Their original Git histories, generated files and personal student ID have not been published here. The snapshots may depend on the UW course environment and should be read as historical coursework, not as four independently maintained applications. The more complete TC1/TC2 implementation is on `main`; a later physical-demo variant is on `remote-physical-demo`.
